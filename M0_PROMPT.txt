BUILD M0 — Hermes Mobile Gateway Scaffold

You are building the Hermes Mobile Gateway: an Android chat app (Expo/React Native) that connects via WebSocket to a Python FastAPI Bridge on a Raspberry Pi, which relays messages to/from a local Hermes Agent. Full build plan is in BUILD_PLAN.md. Design reference is in design/hermes-design.html.

M0 DELIVERABLES:
1. FastAPI Bridge skeleton at bridge/ (Python 3.11, uvicorn, websockets, pydantic v2, httpx, aiosqlite)
2. Shared protocol.ts (Zod schema) at bridge/protocol.ts — then COPY to app/src/protocol/protocol.ts
3. Generate Python pydantic schema from protocol.ts (zod-to-json-schema pattern, write as bridge/pydantic_schema.py)
4. Expo app skeleton at app/ (Expo SDK 54, TypeScript strict, expo-router 3 tabs: Brain/Processes/Settings)
5. Pairing flow: bridge pair CLI minting 32-byte device tokens, QR generation, expo-secure-store storage
6. cloudflared tunnel config mapping hostname to 127.0.0.1:8787

DESIGN TOKENS to hardcode (from the design HTML):

- Font: Geist (300-700), Geist Mono for labels/timestamps
- Bottom tabs: Brain, Processes, Settings

BRIDGE SKELETON (bridge/):
- main.py: FastAPI app with endpoints: GET /ws, POST /files, GET /files/{id}, POST /internal/ui, GET /health
- config.py: settings (port 8787, hermes_url http://127.0.0.1:4700, internal_token from env)
- auth.py: device token hashing (sha256), allowlist from file/env, token validation
- db.py: aiosqlite schema for frame_log (id, chat, ts, seq, kind, payload), uploads metadata, token_allowlist
- pair.py: CLI "bridge pair" that mints 32-byte random token, hashes it, stores in allowlist, prints QR code (use qrcode[pil] package)
- ws.py: WebSocket handler — hello/ping/pong/replay, validate frames against pydantic schema, outbox dedup

APP SKELETON (app/):
- Create with: npx create-expo-app@latest --template tabs
- app/(tabs)/brain.tsx (Chat tab)
- app/(tabs)/processes.tsx
- app/(tabs)/settings.tsx
- src/protocol/protocol.ts (COPIED from bridge/protocol.ts — keep identical)
- src/transport/socket.ts (WS client with auth, heartbeat, backoff reconnect)
- src/store/db.ts (expo-sqlite schema)
- src/theme/tokens.ts (design tokens as constants)
- Install deps: zustand, expo-sqlite, expo-secure-store, expo-router

PROTOCOL.TS:
Define Zod schemas for all frame types: hello, ping, pong, message, stream, typing, receipt, event, edit, error
Each frame: {v:1, id: string(ULID), ts: number, chat: string, from: "user"|"agent", kind: string, ...}
Also define Block types: text, file, voice, buttons, input, slider, select, form, chart, html, card
Export parseFrame(), Frame, Block, etc.

BEFORE WRITING ANY CODE: Read BUILD_PLAN.md fully. Read design/hermes-design.html for visual reference. Then implement everything in order.

AFTER CODE: Verify by running the bridge (python3 -m uvicorn bridge.main:app --host 127.0.0.1 --port 8787) and checking that all imports resolve. For the app, verify that npx expo start would work (don't start it, just check the scaffold is valid).
